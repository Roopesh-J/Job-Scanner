# Job Scanner MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Job Scanner MVP — a Python pipeline that turns a pasted job posting into a structured, traceable extraction (facts → insights → optional candidate fit read), with every insight linked back to the exact source line that justifies it, plus an evaluation harness that reports real precision/recall/grounding numbers, and a local Streamlit UI to use it.

**Architecture:** Three sequential Claude calls, each a pure function operating on typed Pydantic objects: Stage 1 extracts facts from raw posting text (forced tool call), Stage 2 reasons over Stage 1's structured output only (never raw text) to produce insights, Stage 3 optionally compares Stage 1's output against a pasted candidate profile. Every requirement/responsibility carries a verbatim `source_quote`; every insight/fit item carries `supporting_requirement_ids`. Both are validated in code (substring check, ID existence check) immediately after each call — this is the traceability guarantee, not just a data convention.

**Tech Stack:** Python 3.12, `anthropic` SDK (raw, no agent framework), `pydantic` v2, `sentence-transformers` (local embeddings for eval matching), `streamlit` (local UI), `pytest`.

## Global Constraints

- No LangChain/LangGraph — direct Anthropic SDK calls only, per spec §1 (every decision/prompt/response must stay visible and testable).
- Structured output via forced tool calls (`tool_choice={"type": "tool", "name": ...}`), never "please output JSON" prompting, per spec §2.
- IDs for requirements/responsibilities/insights/fit items are assigned by code (`req-1`, `resp-1`, ...), never generated by the model — the model only supplies text/category/quotes; code enumerates them. This avoids relying on the model for bookkeeping it's unreliable at.
- `source_quote` must be an exact verbatim substring of the original posting text — validated with a plain substring check (`quote in posting_text`), never an LLM judge, per spec §2/§3.
- Stage 2 and Stage 3 receive only Stage 1's structured `Posting` object, never the raw posting text, per spec §2 (this is what makes it structurally impossible for them to invent new requirements).
- Unit tests never call the real Anthropic API — `LLMClient` is mocked at the `messages.create` boundary in every test, per spec §4.
- UI (`app.py`) is verified manually (`streamlit run app.py`), not via automated tests, per spec §"Verification" — only its pure helper logic (`ui_helpers.py`) gets unit tests.
- No GitHub remote exists yet; commits are local only (per user instruction, no `git push`).

```python
# job_scanner/models.py
from enum import Enum

from pydantic import BaseModel


class Category(str, Enum):
    REQUIRED = "required"
    PREFERRED = "preferred"
    UNCLEAR = "unclear"


class InsightKind(str, Enum):
    EMPHASIZE = "emphasize"
    INTERVIEW_GAP = "interview_gap"
    PREP_TOPIC = "prep_topic"


class Responsibility(BaseModel):
    id: str
    text: str
    source_quote: str


class Requirement(BaseModel):
    id: str
    text: str
    category: Category
    source_quote: str


class Posting(BaseModel):
    title: str
    company: str
    location: str
    seniority: str
    responsibilities: list[Responsibility]
    requirements: list[Requirement]

    def all_ids(self) -> set[str]:
        return {r.id for r in self.requirements} | {r.id for r in self.responsibilities}


class Insight(BaseModel):
    id: str
    text: str
    kind: InsightKind
    supporting_requirement_ids: list[str]


class FitItem(BaseModel):
    id: str
    text: str
    supporting_requirement_ids: list[str]


class FitRead(BaseModel):
    strengths: list[FitItem]
    gaps: list[FitItem]
```

```python
# job_scanner/validation.py
from job_scanner.models import Posting


class GroundingError(Exception):
    def __init__(self, violations: list[str]):
        self.violations = violations
        super().__init__(f"Ungrounded source quotes for: {', '.join(violations)}")


class ReferenceValidationError(Exception):
    def __init__(self, violations: list[str]):
        self.violations = violations
        super().__init__(f"Unknown requirement/responsibility ids referenced: {', '.join(violations)}")


def find_ungrounded_quotes(posting: Posting, posting_text: str) -> list[str]:
    violations = []
    for req in posting.requirements:
        if req.source_quote not in posting_text:
            violations.append(req.id)
    for resp in posting.responsibilities:
        if resp.source_quote not in posting_text:
            violations.append(resp.id)
    return violations


def find_invalid_references(referenced_ids: list[str], valid_ids: set[str]) -> list[str]:
    return [rid for rid in referenced_ids if rid not in valid_ids]
```

```python
# job_scanner/llm/client.py
import os
from typing import Any

import anthropic

DEFAULT_MODEL = "claude-sonnet-5"


class LLMClient:
    def __init__(self, api_key: str | None = None, model: str = DEFAULT_MODEL):
        self._client = anthropic.Anthropic(api_key=api_key or os.environ.get("ANTHROPIC_API_KEY"))
        self.model = model

    def call_tool(self, system: str, user: str, tool_name: str, tool_schema: dict) -> dict[str, Any]:
        response = self._client.messages.create(
            model=self.model,
            max_tokens=4096,
            system=system,
            messages=[{"role": "user", "content": user}],
            tools=[{"name": tool_name, "description": tool_name, "input_schema": tool_schema}],
            tool_choice={"type": "tool", "name": tool_name},
        )
        for block in response.content:
            if block.type == "tool_use" and block.name == tool_name:
                return block.input
        raise RuntimeError(f"Model response did not include a call to tool '{tool_name}'")
```

```python
# job_scanner/extraction/extractor.py
from job_scanner.llm.client import LLMClient
from job_scanner.models import Category, Posting, Requirement, Responsibility
from job_scanner.validation import GroundingError, find_ungrounded_quotes

EXTRACT_TOOL_NAME = "extract_posting"

EXTRACT_TOOL_SCHEMA = {
    "type": "object",
    "properties": {
        "title": {"type": "string"},
        "company": {"type": "string"},
        "location": {"type": "string"},
        "seniority": {"type": "string"},
        "responsibilities": {
            "type": "array",
            "items": {
                "type": "object",
                "properties": {
                    "text": {"type": "string"},
                    "source_quote": {
                        "type": "string",
                        "description": "Exact verbatim substring copied from the posting text that supports this responsibility.",
                    },
                },
                "required": ["text", "source_quote"],
            },
        },
        "requirements": {
            "type": "array",
            "items": {
                "type": "object",
                "properties": {
                    "text": {"type": "string"},
                    "category": {"type": "string", "enum": ["required", "preferred", "unclear"]},
                    "source_quote": {
                        "type": "string",
                        "description": "Exact verbatim substring copied from the posting text that supports this requirement.",
                    },
                },
                "required": ["text", "category", "source_quote"],
            },
        },
    },
    "required": ["title", "company", "location", "seniority", "responsibilities", "requirements"],
}

SYSTEM_PROMPT = (
    "You are a precise job posting analyst. Extract only what the posting literally "
    "states. Do not infer, assume, or add anything not directly supported by the "
    "text. For every requirement and responsibility, copy an exact verbatim "
    "substring from the posting into source_quote."
)


def extract_posting(posting_text: str, client: LLMClient) -> Posting:
    raw = client.call_tool(
        system=SYSTEM_PROMPT,
        user=posting_text,
        tool_name=EXTRACT_TOOL_NAME,
        tool_schema=EXTRACT_TOOL_SCHEMA,
    )

    responsibilities = [
        Responsibility(id=f"resp-{i + 1}", text=r["text"], source_quote=r["source_quote"])
        for i, r in enumerate(raw["responsibilities"])
    ]
    requirements = [
        Requirement(
            id=f"req-{i + 1}",
            text=r["text"],
            category=Category(r["category"]),
            source_quote=r["source_quote"],
        )
        for i, r in enumerate(raw["requirements"])
    ]

    posting = Posting(
        title=raw["title"],
        company=raw["company"],
        location=raw["location"],
        seniority=raw["seniority"],
        responsibilities=responsibilities,
        requirements=requirements,
    )

    violations = find_ungrounded_quotes(posting, posting_text)
    if violations:
        raise GroundingError(violations)

    return posting
```

```python
    "type": "object",
    "properties": {
        "text": {"type": "string"},
        "supporting_requirement_ids": {"type": "array", "items": {"type": "string"}},
```

```python
    "type": "object",

        "strengths": {"type": "array", "items": _FIT_ITEM_SCHEMA},

        items.append(
            FitItem(
                id=f"{prefix}-{i + 1}",
                text=item["text"],
                supporting_requirement_ids=item["supporting_requirement_ids"],
            )
        )

        system=SYSTEM_PROMPT,
        user=user_message,
        tool_name=FIT_TOOL_NAME,
        tool_schema=FIT_TOOL_SCHEMA,

    valid_ids = posting.all_ids()
    violations: list[str] = []
    strengths = _build_items(raw["strengths"], "strength", valid_ids, violations)
    gaps = _build_items(raw["gaps"], "gap", valid_ids, violations)
```

```python
# job_scanner/eval/matching.py
from dataclasses import dataclass
from typing import Callable

import numpy as np

from job_scanner.models import Requirement


def cosine_similarity(a: list[float], b: list[float]) -> float:
    a_arr, b_arr = np.array(a), np.array(b)
    denom = np.linalg.norm(a_arr) * np.linalg.norm(b_arr)
    if denom == 0:
        return 0.0
    return float(np.dot(a_arr, b_arr) / denom)


@dataclass
class MatchResult:
    matched_pairs: list[tuple[Requirement, Requirement]]
    false_positives: list[Requirement]
    false_negatives: list[Requirement]


def match_requirements(
    predicted: list[Requirement],
    reference: list[Requirement],
    embed_fn: Callable[[list[str]], list[list[float]]],
    threshold: float = 0.7,
) -> MatchResult:
    if not predicted or not reference:
        return MatchResult(matched_pairs=[], false_positives=list(predicted), false_negatives=list(reference))

    pred_vectors = embed_fn([r.text for r in predicted])
    ref_vectors = embed_fn([r.text for r in reference])

    matched_pairs = []
    used_ref_indices: set[int] = set()
    false_positives = []

    for i, pred in enumerate(predicted):
        scores = [cosine_similarity(pred_vectors[i], ref_vec) for ref_vec in ref_vectors]
        best_j = max(range(len(scores)), key=lambda j: scores[j])
        if scores[best_j] >= threshold and best_j not in used_ref_indices:
            matched_pairs.append((pred, reference[best_j]))
            used_ref_indices.add(best_j)
        else:
            false_positives.append(pred)

    false_negatives = [r for j, r in enumerate(reference) if j not in used_ref_indices]

    return MatchResult(matched_pairs=matched_pairs, false_positives=false_positives, false_negatives=false_negatives)
```

```python
# job_scanner/eval/metrics.py
from dataclasses import dataclass, field

from job_scanner.eval.matching import MatchResult
from job_scanner.models import Posting
from job_scanner.validation import find_ungrounded_quotes


@dataclass
class RequirementMetrics:
    precision: float
    recall: float
    true_positives: int
    false_positives: int
    false_negatives: int


def compute_requirement_metrics(match: MatchResult) -> RequirementMetrics:
    tp = len(match.matched_pairs)
    fp = len(match.false_positives)
    fn = len(match.false_negatives)
    precision = tp / (tp + fp) if (tp + fp) else 0.0
    recall = tp / (tp + fn) if (tp + fn) else 0.0
    return RequirementMetrics(precision=precision, recall=recall, true_positives=tp, false_positives=fp, false_negatives=fn)


@dataclass
class CategoryConfusionMatrix:
    counts: dict[tuple[str, str], int] = field(default_factory=dict)

    def accuracy(self) -> float:
        total = sum(self.counts.values())
        if total == 0:
            return 0.0
        correct = sum(count for (predicted, reference), count in self.counts.items() if predicted == reference)
        return correct / total


def compute_category_confusion(match: MatchResult) -> CategoryConfusionMatrix:
    matrix = CategoryConfusionMatrix()
    for predicted, reference in match.matched_pairs:
        key = (predicted.category.value, reference.category.value)
        matrix.counts[key] = matrix.counts.get(key, 0) + 1
    return matrix


def compute_grounding_accuracy(posting: Posting, posting_text: str) -> float:
    total = len(posting.requirements) + len(posting.responsibilities)
    if total == 0:
        return 1.0
    violations = find_ungrounded_quotes(posting, posting_text)
    return 1 - (len(violations) / total)
```

```python
def load_reference_set(data_dir: Path) -> list[EvalCase]:
    cases = []
    for text_path in sorted(data_dir.glob("*.txt")):
        label_path = text_path.with_suffix(".json")
        if not label_path.exists():
            continue
        posting_text = text_path.read_text()
        reference = Posting.model_validate_json(label_path.read_text())
        cases.append(EvalCase(name=text_path.stem, posting_text=posting_text, reference=reference))
    return cases


def run_evaluation(data_dir: Path, client: LLMClient, threshold: float = 0.7) -> dict:
    cases = load_reference_set(data_dir)
    per_case = []

    for case in cases:
        try:
            predicted = extract_posting(case.posting_text, client)
        except GroundingError as e:
            per_case.append({"name": case.name, "error": str(e)})
            continue

        match = match_requirements(
            predicted.requirements,
            case.reference.requirements,
            embed_fn=sentence_transformer_embed_fn,
            threshold=threshold,
        )
        req_metrics = compute_requirement_metrics(match)
        confusion = compute_category_confusion(match)
        grounding_accuracy = compute_grounding_accuracy(predicted, case.posting_text)

        per_case.append(
            {
                "name": case.name,
                "precision": req_metrics.precision,
                "recall": req_metrics.recall,
                "category_accuracy": confusion.accuracy(),
                "grounding_accuracy": grounding_accuracy,
            }
        )

    return {"cases": per_case}


def save_report(report: dict, output_path: Path) -> None:
    output_path.write_text(json.dumps(report, indent=2))
```

```python
# job_scanner/ui_helpers.py
from job_scanner.models import Posting


def build_id_lookup(posting: Posting) -> dict[str, str]:
    lookup = {r.id: r.source_quote for r in posting.requirements}
    lookup.update({r.id: r.source_quote for r in posting.responsibilities})
    return lookup


def format_sources(supporting_ids: list[str], id_lookup: dict[str, str]) -> str:
    quotes = [id_lookup[rid] for rid in supporting_ids if rid in id_lookup]
    return ", ".join(f"“{q}”" for q in quotes)
```

```python
import os

import streamlit as st

from job_scanner.analysis.analyzer import generate_insights
from job_scanner.extraction.extractor import extract_posting
from job_scanner.fit.fit_analyzer import generate_fit_read
from job_scanner.llm.client import LLMClient
from job_scanner.ui_helpers import build_id_lookup, format_sources
from job_scanner.validation import GroundingError, ReferenceValidationError

st.set_page_config(page_title="Job Scanner", layout="wide")
st.title("Job Scanner")

posting_text = st.text_area("Job posting", height=250)
profile_text = st.text_area("Candidate profile (optional)", height=150)

if st.button("Analyze", disabled=not posting_text.strip()):
    client = LLMClient(api_key=os.environ.get("ANTHROPIC_API_KEY"))

    with st.spinner("Extracting posting..."):
        try:
            posting = extract_posting(posting_text, client)
        except GroundingError as e:
            st.error(f"Extraction failed a traceability check: {e}")
            st.stop()

    id_lookup = build_id_lookup(posting)

    st.subheader(f"{posting.title} — {posting.company}")
    st.caption(f"{posting.location} · {posting.seniority}")

    st.subheader("Requirements")
    for req in posting.requirements:
        st.markdown(f"**[{req.category.value}]** {req.text}")
        st.caption(f"Source: {format_sources([req.id], id_lookup)}")

    with st.spinner("Generating insights..."):
        try:
            insights = generate_insights(posting, client)
        except ReferenceValidationError as e:
            st.error(f"Analysis failed a traceability check: {e}")
            insights = []

    if insights:
        st.subheader("Insights")
        for insight in insights:
            st.markdown(f"**[{insight.kind.value}]** {insight.text}")
            sources = format_sources(insight.supporting_requirement_ids, id_lookup)
            if sources:
                st.caption(f"Why: {sources}")

    if profile_text.strip():
        with st.spinner("Generating fit read..."):
            try:
                fit_read = generate_fit_read(posting, profile_text, client)
            except ReferenceValidationError as e:
                st.error(f"Fit read failed a traceability check: {e}")
                fit_read = None

        if fit_read:
            st.subheader("Fit read")
            st.markdown("**Strengths**")
            for item in fit_read.strengths:
                st.markdown(f"- {item.text}")
                sources = format_sources(item.supporting_requirement_ids, id_lookup)
                if sources:
                    st.caption(f"Why: {sources}")
            st.markdown("**Gaps**")
            for item in fit_read.gaps:
                st.markdown(f"- {item.text}")
                sources = format_sources(item.supporting_requirement_ids, id_lookup)
                if sources:
                    st.caption(f"Why: {sources}")
```
